# The paint index

`index.tsv` is generated by `scripts/paint_index.py` from the tables of
[miniature-paints](https://github.com/Arcturus5404/miniature-paints),
copyright 2022 Rick Fleuren, MIT licensed (`LICENSE-miniature-paints`).
Generated from commit `22791a682e1d155da388f4f856cd7196cd9f2677` of those
tables on 2026-11-25.

One paint a line, tab separated: brand, product line, name, product code,
colour as six hex digits, kind, and flags (`a` airbrush, `s` spray, `D`,
`B` and `L` for the dark, base and light of a Foundry triad).

The kind is the script's guess from the product line and the name,
corrected by `scripts/paint_overrides.tsv`. See `docs/PAINT-RACK.md`,
section 2.

To regenerate it:

```bash
scripts/paint_index.py path/to/miniature-paints/paints assets/paints/index.tsv
```
